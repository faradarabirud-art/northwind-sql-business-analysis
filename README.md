# Northwind SQL Business Analysis Project

## Project Overview

This project analyses the Northwind Traders dataset using SQL from the perspective of a Junior Business Analyst. The objective is to understand sales performance, product performance, customer value, and business trends using relational database analysis.

## Business Objectives

- Analyse overall sales performance
- Identify top-performing product categories
- Find the highest-revenue products
- Analyse monthly sales trends
- Identify valuable customers
- Understand sales performance by country
- Evaluate employee sales contribution
- Analyse discount impact and delivery performance

## Tools Used

- MySQL
- MySQL Workbench
- GitHub

## Dataset

The project uses the Northwind dataset, which includes information about:

- Customers
- Orders
- Order details
- Products
- Categories
- Employees
- Shippers

## Database Structure

The main table relationships are:

- Customers to Orders
- Employees to Orders
- Shippers to Orders
- Orders to Order Details
- Products to Order Details
- Categories to Products

## SQL Skills Demonstrated

- SELECT statements
- JOINs
- GROUP BY
- ORDER BY
- Aggregate functions
- COUNT DISTINCT
- Revenue calculations
- Discount calculations
- Business KPI analysis
- Data quality validation

## Completed Business Analysis

1. Executive KPI Summary

## Key Business Questions

The project answers questions such as:

- What is the overall sales performance of the business?
- Which product categories generate the highest revenue?
- Which products are the strongest revenue drivers?
- How does sales performance change over time?
- Which customers contribute the most revenue?
- Which countries generate the highest sales?
- Which employees handle the highest sales value?
